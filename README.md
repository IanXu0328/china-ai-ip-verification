# 中国 AI 知识产权判例核验库

聚焦中国 AI 知识产权领域的真实判例与司法规则，强调**真实、可核验、结构化、可复用**。
每个案例都附带核验路径，所有结论可追溯到权威来源。

## 项目定位

- 不是简单的案例搬运，而是「人机协同」工作流产出的结构化知识库；
- 只收录有真实案号、官方来源、可交叉核验的判例；
- 记录 AI 在法律问答中的典型幻觉，作为避坑参考。

## 核心特色：AI 工作流

本库内容采用「人机协同（Human-in-the-loop）」流程产出：

1. AI 初筛检索相关判例；
2. 用定制化 Prompt 做结构化摘要；
3. AI 幻觉核查 + 人工在裁判文书网交叉核验；
4. 把识别出的幻觉记录入库。

详见 `tools/workflow.md`。
