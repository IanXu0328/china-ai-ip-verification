# 本项目 AI 工作流 (Workflow)

本仓库的所有案例并非纯人工堆砌，而是采用“人机协同（Human-in-the-loop）”的标准化工作流产出，这也是本项目最大的技术亮点。

## 1. 初筛与检索
- **工具**：法律专业 AI 模型
- **操作**：向 AI 投喂海量裁判文书，要求其筛选出包含“AI”、“人工智能”、“算法”等关键词，且涉及著作权、不正当竞争的最新中国司法判例。

## 2. 结构化提取
- **工具**：AI 判例摘要提示词 (`tools/case-summarizer.md`)
- **操作**：将筛选出的原始裁判文书投喂给 AI，利用定制化 Prompt 快速提取出案件要素、裁判理由与核心争议，生成 Markdown 格式初稿。

## 3. 幻觉核查与人工核验
- **工具**：AI 幻觉核查提示词 (`tools/hallucination-checker.md`) + 裁判文书网
- **操作**：使用专门的核查 Prompt 让 AI 进行第一轮“自我纠错”。随后，由人工逐条在裁判文书网或官方通报中交叉验证，确保每一个案号、金额、法条引用绝对真实。

## 4. 幻觉记录入库
- **操作**：将 AI 在核查阶段被识别出的典型幻觉（如编造法条、混淆概念）记录到 `hallucination-log.md` 中，作为后续训练和避坑的参考。
